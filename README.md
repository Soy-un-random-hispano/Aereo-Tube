## English

**AeroTube** turns YouTube into a Frutiger Aero daydream: liquid glass UI, soft caustics, glossy buttons, and wallpapers that look like a Vista desktop came back to life.

Built with Grok. Made for Chromium-based browsers (Chrome, Edge, Brave, Opera…).

### What’s included

- **Chrome extension** — injects the theme on real `youtube.com`
- **Live preview site** — try the look before installing: [aereo-tube.vercel.app](https://aereo-tube.vercel.app)
- **Instant controls** — wallpaper, bubbles, glass intensity, accent color (aqua / lime / sunset)
- **UI in your language** — English, Spanish, or Portuguese (falls back to English)

### Install the extension

1. Download [`public/aero-tube.zip`](public/aero-tube.zip) (or grab it from the [demo install page](https://aereo-tube.vercel.app/install))
2. Unzip it — you need the folder that contains `manifest.json`
3. Open `chrome://extensions`
4. Enable **Developer mode**
5. Click **Load unpacked** and select that folder
6. Open [youtube.com](https://www.youtube.com) — the theme applies automatically

> Chrome does not install extensions from random websites for security reasons. Unpacked + developer mode is the normal way to side-load this.

### Customize

Click the **AeroTube** icon in the toolbar:

| Control | What it does |
| --- | --- |
| Theme on | Toggle the whole look |
| Wallpaper | Lagoon, Sky, Orbs, Hills |
| Bubbles | Floating glass orbs |
| Glossy buttons | Shiny chrome-style controls |
| Glass intensity | How strong the blur / glass is |
| Accent | Aqua, Lime, Sunset |

Settings sync via Chrome storage across YouTube tabs.

### Project layout

```text
public/extension/   ← the actual extension (load this folder)
public/aero-tube.zip
public/aero/        ← icons, wallpapers, demo thumbs
src/                ← live demo web app
```

### Notes

- Works on `youtube.com` / `www.youtube.com` / `m.youtube.com`
- Does **not** theme YouTube Music or YouTube Studio
- YouTube’s DOM changes often — if something breaks after a site update, open an issue
