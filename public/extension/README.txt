AeroTube — Frutiger Aero para YouTube
====================================

1. Abre chrome://extensions
2. Activa "Modo de desarrollador"
3. Pulsa "Cargar descomprimida"
4. Elige ESTA carpeta (la que contiene manifest.json)
5. Abre https://www.youtube.com

El icono de AeroTube en la barra abre wallpaper, burbujas,
intensidad del cristal y color de acento.
